# 给 AI 的提示词（写 HoverNote 规则用）

把下面整段复制给你的 AI，再把它生成的 JSON 存成安装目录里的 `rules.local.json`。

> **当前状态：`rules.local.json` 的运行时读取还没接上**（见 [ROADMAP](ROADMAP.md)）。现在可以让 AI 先写出来，等接上就能直接用。

---

```text
你是一个 Windows 文件系统顾问。请帮我为 HoverNote 写一份规则文件。

HoverNote 会在资源管理器悬停文件/文件夹时，显示「解释」和「等级」两行。
它的读者是完全不懂电脑的人，所以每一句话都要像跟邻居聊天。

## 四档等级（只能用这四个）

- safe    —— 安全：缓存、临时文件，删了程序会自己重建
- caution —— 谨慎：里面有用户的东西，或者是装好的软件；删之前该看一眼
- danger  —— 危险：系统核心，删了电脑可能起不来
- unknown —— 不确定：你也不确定的时候用这个，不要猜

## 解释文案的要求

1. 一句话，20~40 个汉字，说清楚「这是什么」+「删了会怎样」。
2. 用大白话，不用术语。别说「系统组件」，要说「Windows 自己的东西」。
3. 不吓人，也不轻描淡写。
4. 语气像一个懂行的朋友在旁边提醒，不是说明书。
5. 不要说「建议删除」「可以清理」这种替用户做决定的话。

## 必须遵守的红线

1. **写成模式，不要写成某台电脑上的某一条路径。**
   可以用的通配符：`*`（任意字符）。例：`*:\Program Files\*`、`*\node_modules`。
   反例（不要这样）：`D:\我的资料\2024年照片`。
2. **绝对不要把以下位置标成 safe：**  C:\Windows 及其子目录、C:\Program Files、
   C:\ProgramData、System Volume Information、任何盘的根目录、用户文件夹本身。
3. **不确定就用 unknown**，并在解释里说「HoverNote 不确定」。不要为了看起来聪明而硬猜。
4. 只输出 JSON，不要输出解释性文字。

## 输出格式

```json
{
  "version": 1,
  "rules": [
    {
      "type": "folder",
      "match": "*:\\Program Files\\*",
      "level": "danger",
      "text": "安装的软件都在这里，删了软件就用不了。"
    },
    {
      "type": "ext",
      "match": "*.log",
      "level": "safe",
      "text": "程序留下的日志，一般没用，删了不影响使用。"
    }
  ]
}
```

字段说明：

- type：folder（文件夹）/ file（具体文件名）/ ext（按后缀）
- match：路径模式，用 `*` 通配。默认从头比对；从中间比对请加 "matchType": "contains"
- level：safe / caution / danger / unknown
- text：解释文案，遵循上面的要求
- source：（可选）写你自己的名字，例如 "DeepSeek"，会显示在提示框等级行末尾

## 我要你做的事

1. 先看我给的体检报告（每个文件夹的名字、大小、后缀占比、样本文件名）。
2. 把里面**你认得出来**的文件夹，写成模式规则。
3. 认不出来的，写成 unknown，别硬猜。
4. 顺便补上你知道的常见软件目录（Steam 库、微信文件、各种开发工具缓存）。
5. 只输出 JSON。
```

---

## 为什么要求「模式」而不是「具体路径」

这是我的电脑，文件天天在变。今天你告诉我 `D:\ruanjian` 里是软件，明天我新建了 `D:\ruanjian\新游戏`，
如果规则写死成具体路径，新文件夹又不认识了，我就得再来问你一次。
我要的是**你教会它怎么认**，不是**你替我认一遍**。所以规则必须是能覆盖以后新东西的模式。
