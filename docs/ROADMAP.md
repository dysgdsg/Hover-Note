# 路线图

这份文件只做一件事：说清楚**哪些是真的、哪些还没做**。免得大家误以为某个功能已经能用了。

## 已经能用

- [x] 在资源管理器提示框里注入「解释 / 等级」两行（不改系统原生外观）
- [x] 四档等级 + 78 条内置规则（系统目录、用户文件夹、常见后缀）
- [x] 运行时认路：问 Windows 要桌面/下载/文档的真实位置（跨盘也准）
- [x] 按文件夹「长相」判断：卸载程序、可执行文件、工程文件、图片、视频、快捷方式
- [x] 兜底说规模，而不是硬猜
- [x] 认不出来就返回空，交还系统原生提示（无痕）
- [x] 免管理员安装 / 卸载，只写 HKCU
- [x] 体检报告导出（每个文件夹一行摘要，给 AI 看）

## 正在做

- [ ] **`rules.local.json` 运行时加载**：让 AI 写的规则真的生效
  - 读取顺序：`rules.local.json`（用户/AI 写的） > 内置 `rules.json`
  - 硬编码的系统危险底线 > 一切外部规则（防止 AI 把 C:\Windows 写成「安全」）
  - 解析失败：整份作废，回退内置；写前先备份
- [ ] **下载包的说明**：`.exe/.msi/.zip` 现在能说「谨慎」，但还不会说「这可能是你在装的新软件」
  - 可用信号：后缀 + `Zone.Identifier` 下载标记 + 所在目录（下载夹）

## 明确不做

这些不是「还没做」，是**想清楚了不做**，理由都记着：

- **常驻后台 / 开机自启**：净收益几乎为零。新建文件夹靠名字和长相就能认；AI 规则改完，悬停时看一眼文件修改时间就知道要不要重读。常驻只会多占内存、多一个开机项。
- **本地跑小模型**：400MB~2GB，每次判断 0.2~2 秒，还会被杀软当可疑程序。为了猜一个文件夹是啥，代价太大。
- **联网识别**：违背「不联网、不上传」。
- **自动清理 / 一键删垃圾**：这不是这个项目要做的事。它只负责让你看懂，动手是你自己。
