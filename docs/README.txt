HoverNote 使用说明
==================

一、这是干什么的
----------------
在文件夹窗口里，把鼠标停在某个文件或文件夹上，Windows 会弹出一个小黄框。
HoverNote 会在这个小黄框里，多加两行大白话：

    解释   这是什么东西，删了会怎么样
    等级   安全 / 谨慎 / 危险 / 不确定

一句话：它不是帮你清理垃圾的，它是帮你在删东西之前，先弄明白"这玩意儿到底是啥"。


二、怎么用
----------
装好以后，不需要打开任何窗口，也没有什么图标要双击。
直接像平时一样：打开"此电脑"，把鼠标停在文件上，等一两秒，看提示框。

四档等级的意思：

    危险 · 系统核心，别删              → 动了电脑可能坏，不要删
    谨慎 · 删前先看一眼里面的东西      → 里面可能有你的东西，删之前点开看看
    安全 · 可以放心删                  → 是缓存/临时文件，删了程序会自己重建
    不确定 · 建议先别动                → HoverNote 不认识，不给你瞎出主意


三、它不会做什么
----------------
· 不会删你的任何文件，一个都不会。
· 不会在后台常驻，也不开机自启。你不用它的时候，它不在运行。
· 不会联网，不会上传你的文件名和路径。
· 不会改系统设置，只在你自己的用户设置里加了几条（卸载时全部删干净）。


四、怎么卸载
------------
打开安装目录（就是你安装时填的那个位置；如果没改过，是这里）：

    C:\Users\你的用户名\AppData\Local\HoverNote

安装时如果提示"访问被拒绝"，是安全软件挡住了这个没签名的新程序：
点"换个地方…"换个文件夹，或者暂时退出安全软件，再装一次。

双击里面的 Uninstall.exe，点"是"，就卸干净了：
注册表那几条删掉，三个文件也删掉。

如果你把 Uninstall.exe 弄丢了，也可以手动处理，但更推荐重新装一遍再卸载。


五、看不到提示框？
------------------
Windows 的资源管理器会"记住"已经加载过的旧版本。刚装完如果没反应：

    重启一次电脑就好。

（重启是最稳的办法，别用各种"重启资源管理器"的偏方。）


六、已知的限制（说实话）
------------------------
1. 规则是我一条条整理的"经验规则"，不是微软官方数据库。
   没见过的文件，它会老实说"不确定"，不会硬猜。
2. 只保证 Windows 11 能用。Windows 10 没测过。
3. 压缩包"里面"的文件悬停不了（那时候还没有真正的文件路径）。
4. 大小是文件本身的大小；文件夹只显示"文件夹"，不统计里面有多大（统计会很慢）。
5. 从网上下载的文件，会显示"从哪个网站下载来的"（只显示域名，不显示完整网址）。


七、让它更懂你这台电脑（可选）
--------------------------------
我出厂只认识最常见的位置。你这台电脑的特殊情况——软件装在 D 盘、
自己建的 "ruanjian" 这种文件夹——可以让 AI 帮你补。

做法：
  1. 双击安装程序（装过的也能双击，不会重装，别点"开始安装"就行）。
  2. 点左边那个"生成体检报告"。
  3. 桌面上会出现 HoverNote-体检报告.txt。

这份报告里只有：文件夹叫什么、多大、里面有哪些后缀、三个样本文件名。
不读文件内容，不联网，不上传。

把它发给 AI（豆包、DeepSeek 都行），跟它说一句：
"按这份报告，帮我写 HoverNote 的规则"。

（提醒：AI 写规则这半截还在做，现在报告能生成，但 rules.local.json
 还不会生效。先把报告留着，下一版接上。给 AI 的现成提示词见项目里的
 docs\AI-规则提示词.md。）


八、开源与许可
--------------
GPL-3.0 许可证。源码在 GitHub 上，想改、想学、想接着做都行。

如果你觉得某个文件夹"它说错了"，欢迎去 GitHub 提个 issue，说清楚：
你悬停的是什么、它说了什么、你觉得该说什么。这类反馈最值钱。

改了以后再发布的话，记得也把源码公开——这是 GPL 的要求，也是它
能一直长下去的原因。


谢谢你愿意试试它。
