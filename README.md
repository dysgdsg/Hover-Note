# HoverNote

> 在「删除」和「后悔」之间，加一句话。

Windows 资源管理器里，鼠标停在文件或文件夹上时，系统会弹一个小提示框。HoverNote 在这个框里**多加两行大白话**：这是什么、删了会怎么样。

```text
大小   12.3 MB
修改   2025-03-14 10:22
解释   Chrome 的网页缓存，删了会自动重建。
等级   安全 · 可以放心删
```

就这样。它不清理垃圾、不弹窗打扰、不在后台常驻，也不用你打开任何界面。

## 四档等级

| 等级 | 意思 |
|---|---|
| 安全 · 可以放心删 | 缓存、临时文件，删了程序会自己重建 |
| 谨慎 · 删前先看一眼里面的东西 | 里面有你的东西，或者是个软件/游戏，删之前先点开看看 |
| 危险 · 系统核心，别删 | 动了电脑可能开不了机 |
| 不确定 · 建议先别动 | 它不认识，就老实说不知道，不瞎出主意 |

## 快速开始

1. 到 [Releases](https://github.com/dysgdsg/Hover-Note/releases) 下载 `HoverNote-Setup.exe`
2. 双击运行（**不需要管理员权限**，也不写系统目录）
3. 打开任意文件夹，把鼠标停在文件上等一两秒

装好之后只有三个文件，卸载时一个都不留：

```text
%LOCALAPPDATA%\HoverNote\
    HoverNote.dll      ← 干活的就是它
    Uninstall.exe      ← 想删就双击这个
    README.txt         ← 说明，看不看都行
```

注册表只在当前用户下动五处（`HKCU\Software\HoverNote` 和 shell 扩展的 CLSID 那几项），卸载时全删。

## 它是怎么判断的

它不会去猜文件内容，也不会联网问 AI。判断分三层，从硬到软：

1. **死规矩**（内置 `rules/rules.json`，78 条）：系统目录、用户文件夹、常见后缀。这些永远不变。
2. **现场认路**（运行时查）：
   - 直接问 Windows「桌面/下载/文档/图片在哪」——所以你把文件夹搬到 D 盘它也认得
   - 看文件夹「长相」：里面有 `uninstall.exe` → 装了个软件；有一堆 `.exe/.dll` → 软件或游戏；有 `.git`、`.sln`、`.blend` → 你自己做的东西；全是图片 → 照片
   - 看名字：`Temp`、`Cache`、`node_modules`、`__pycache__` → 缓存
3. **兜底**：都不认识就说规模（「里面是 6 个文件夹」）+ **不确定**，让你自己判断。

判断用的信息只有：**名字、大小、修改时间、扩展名、还剩多少同类文件**。

## 它不做什么

- 不删任何文件。它只解释，不动手。
- 不联网、不上传。没有服务器，没有统计，没有崩溃上报。
- 不常驻、不开机自启。只在弹提示框那一瞬间跑一下。
- 不读文件内容。连 `.docx` 里写了什么它都不知道，只认得后缀。
- 不改系统设置。

唯一的例外：如果文件带着从网上下载的标记（`Zone.Identifier`），它会多说一句「从哪个网站下载来的」（只显示域名）。

## 已知限制（说实话）

- 只保证 **Windows 11** 能用；Windows 10 没测过。
- **文件夹不显示大小**：统计文件夹要遍历整棵目录树，会让悬停卡顿，所以只显示「文件夹」。
- **压缩包里**的文件悬停不了——那时候还没有真实路径。
- **规则靠人攒**：没见过的位置会说「不确定」。这是设计，不是 bug。
- **没有数字签名**（个人项目，签名证书要花钱），所以火绒/360 这类安全软件可能会拦第一次安装。被拦的话：换个安装目录，或者临时退出安全软件再装。

## 让它更懂你这台电脑

出厂只认识最常见的位置。如果你的软件都装在 D 盘、或者有 `D:\ruanjian` 这种自己起的名字，可以让 AI 帮你补规则。

1. 双击安装程序，点「生成体检报告」
2. 得到一份 `HoverNote-体检报告.txt`：里面是每个文件夹的名字、大小、后缀占比、三个样本文件名。**不读文件内容，不联网，不上传。**
3. 把这份报告发给你常用的 AI，说一句「按这份报告，帮我写 HoverNote 的规则」

> 这一步目前是**半成品**：报告已经能生成，但 `rules.local.json` 的运行时读取还没接上。规划见 [docs/ROADMAP.md](docs/ROADMAP.md)。

## 从源码构建

不需要 .NET SDK，只用 Windows 自带的 C# 编译器（.NET Framework 4.x）：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools\build.ps1
```

产物：`bin\HoverNote.dll`、`dist\HoverNote-Setup.exe`、`dist\Uninstall.exe`。

自测（不装也能看效果）：

```powershell
bin\TestHarness.exe /dll bin\HoverNote.dll "C:\Windows" "C:\Users" "D:\"
```
